# Dota Helper — план разработки

## 0.6 — данные и иконки (реализовано)

- Valve/Steam оригинальные изображения во всех списках и слотах драфта.
- STRATZ heroStats.stats(groupByPosition) — наблюдаемые позиции 1–5, без ручных пулов; обновление кэша 3 часа.
- STRATZ heroStats.matchUp — matchup по выбранной базовой группе из двух медалей; кэш 6 часов.
- Предпочитаем STRATZ, а при ошибке используем подписанный OpenDota matchup.
- Приоритет контрпиков всех противников с дополнительным весом для позиций 1–3 и врагов на линии.
- Для матчапа STRATZ оцениваем преимущество по сравнению с общим WR героя в той же паре медалей. OpenDota сравнивается с 50% как отдельная приблизительная схема.
- Не называем эти данные «текущим патчем», пока не подтверждена и не внедрена фильтрация по версии.

## Требуется проверить в пользовательском окружении

1. Получить STRATZ_API_TOKEN лично, не публикуя его в репозитории.
2. Проверить GraphQL на реальном токене (ответы разных рейтингов и новых героев).
3. Проверить отображение портретов из Steam CDN на Windows.
4. Проверить изменение кандидатов при переключении ранга и противников.
5. Сопоставить контрпики STRATZ с результатами матчей; коэффициенты модели пока эвристические.

## Дальнейшая работа

- Патч-специфическая статистика позиций и противостояний, если STRATZ поддерживает такую фильтрацию.
- Калибровка веса противников и доверительных интервалов по независимой выборке.
- Синергии, потребности команды по ролям и ограничения драфта.
- Поддержка пользовательских Steam ссылок /id/ через безопасное разрешение.
- Проверка автоматического распознавания драфта разрешёнными средствами.
