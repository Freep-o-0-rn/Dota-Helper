# Dota Helper — план

## 0.5 — реальная статистика ролей STRATZ (реализовано)

- Удалён `PositionProfile.cs` с ручными списками героев для позиций 1–5.
- Стандартный пул использует только наблюдаемые счётчики `heroStats.stats(groupByPosition: true)` из STRATZ.
- Проверка по матчам: минимум 30 игр и 5% распределения по ролям; эти числа предварительные, требуют объективной валидации.
- Пары медалей STRATZ: 1–2, 3–4, 5–6, 7–8. Точность до одной медали отсутствует.
- Без токена и кэша стандартные рекомендации не делаются, экспериментальные явно помечаются.
- Для рейтинговой меты — WR на выбранной роли из STRATZ. Для профессиональной — общий pro_pick/pro_win из OpenDota; ролевая выборка берётся из высокорейтингового STRATZ, не только профессиональных матчей.
- Контрпики всей вражеской команды остаются из общих данных лиг OpenDota; не выдаём их за статистику по рангу, позиции или патчу.
