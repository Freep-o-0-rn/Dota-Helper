# Dota Helper — план разработки

## 0.11 — экранный All Pick (экспериментальная реализация)

- Windows primary monitor capture, проверка активного окна Dota 2.
- Калибровка 3 областей экранной игры через визуальную разметку.
- Оригинальные Steam CDN изображения как шаблоны героев; нормализованное grayscale-сопоставление и минимальный отрыв от второго кандидата.
- Для банов — поиск красных диагоналей, классификация соответствующих портретов, подтверждение на двух последовательных снимках.
- Только дополнять пустые слоты; ручные решения не удалять и не переопределять. Данные GSI приоритетнее экранной эвристики.
- Тесты на синтетических портретах/красной диагонали; окончательная проверка требует скриншота **реального драфта All Pick** и разрешения пользователя.
- Далее: подобрать пороги и геометрию для настоящих скриншотов Dota 2, улучшить работу с несколькими мониторами, сменой разрешения и хранением шаблонов.



## 0.10 — GSI-подключение и крупнее иконки

- Портреты 48×32 в ручном выборе, с сохранением пропорций.
- Приёмник Valve GSI только localhost, установка конфигурации через UI, кнопка подключения и отключения, диагностика потери пакетов.
- Поддержка реальных ID пиков/банов из `draft.team2/team3`; заполнение только пустых слотов, без удаления данных при неполных пакетах.
- Отдельная обработка банов All Pick и Captains Mode, корректировка собственной команды по `player.team_name` если игра прислала.
- Очистка только GSI-добавленных слотов при достоверной смене `matchid`.
- Ограничение: в All Pick GSI может не передавать пиковую информацию для всех игроков. Следующий этап — *опциональное экранное распознавание* видимых героев (без вмешательства в игру, с пользовательской проверкой и откатом при неуверенности).
- Windows CI и smoke-тесты обработки доступной/недоступной GSI-информации.



## 0.9.1 — Dota-style поиск (реализовано)

- Не фильтруем портреты с перестройкой сетки: оставляем все и затемняем несовпадения.
- Русский официальный каталог Valve + автоматическая транслитерация/исправление RU↔EN раскладки + распространённые сокращения.
- Первая печать сразу направляется в поле поиска, поддержка Enter/Escape.
- Тесты на русские/английские названия, «вд», «шд», «легион», «вк», неверную раскладку и нового героя.
- Для реального времени следующий этап: использовать доступные локальные данные Dota GSI и отдельно исследовать экранное распознавание пиков All Pick. GSI нельзя считать полным источником драфта во всех режимах.



## 0.9 — Radiant/Dire board и модернизация интерфейса

- Три основные колонки: слева настройки, по центру пики и баны, справа рекомендации.
- Быстрый поиск героя по нажатию на портрет, предпросмотр своего пика, разметка вражеских позиций и линии.
- All Pick: общие бан-слоты (18 ячеек вместимости редактора), Captains Mode: семь на Radiant, семь на Dire.
- Исключение забаненных героев из рекомендаций при сохранении неизменной модели баллов.
- Приглушённые тонкие скроллбары, скругления, тёмные поля и кнопки, скрываемые детали.
- Проверка на Windows и исправление оставшихся проблем DPI/выбора/размеров после пользовательского тестирования.


## 0.8.2 — UI/UX (реализовано)

## 0.8.1 — корректная интерпретация роли и UX

- Частота выбора роли STRATZ и количество матчей показываются в рекомендациях, не смешиваются с винрейтом.
- Бонус соответствия роли теперь пропорционален эмпирической распространённости и объёму выборки, а не фиксированным +6 всем кандидатам.
- Riki/Snapfire mid остаются в стандартном пуле, когда выборка подтверждает их пригодность; нет ручных исключений.
- Настройки профиля/API и справка сворачиваются, основные селекторы доступны сразу.
- Один драфт; не добавляем переключение обычный/тестовый.



## 0.8 — патч и качество данных (реализовано)

- Valve patchnoteslist: официальный номер и дата текущего опубликованного патча; кэш 12 часов, офлайн-режим. Номер патча не приписывается историческим агрегатам STRATZ.
- Matchup shrinkage к собственному baseline каждого источника: STRATZ — общий WR кандидата в выбранной категории рангов; OpenDota — нейтральная база 50%, priorGames=200.
- Полнота и надёжность контрпиков вычисляется по взвешенному покрытию всех противников с учётом объёма игр. Не трактовать как вероятность победы.
- Автотесты кэша/разбора patchnoteslist и устойчивости к малым выборкам.

## 0.7 — синергии и ссылки Steam (реализовано)

- STRATZ heroStats.matchUp.with: выборка совместных матчей каждого союзника и кандидата, кэш 6 ч, при отсутствии данных — нейтральный эффект.
- Доли синергии сглаживаются к нейтральному результату; вклад ограничен ±7 баллами, контрпики остаются ±17.
- Для каждой рекомендации показываем вклад и размер выборки совместных матчей.
- Steam vanity /id/ разрешается в 32-битный account ID через публичный Steam Community XML (устаревший интерфейс, поэтому предусмотрено честное сообщение об ошибке).
- Не внедрены патч-фильтр и полноценная профессиональная выборка для синергий.

## 0.6 — данные и иконки (реализовано)

- Valve/Steam оригинальные изображения во всех списках и слотах драфта.
- STRATZ heroStats.stats(groupByPosition) — наблюдаемые позиции 1–5, без ручных пулов; обновление кэша 3 часа.
- STRATZ heroStats.matchUp — matchup по выбранной базовой группе из двух медалей; кэш 6 часов.
- Предпочитаем STRATZ, а при ошибке используем подписанный OpenDota matchup.
- Приоритет контрпиков всех противников с дополнительным весом для позиций 1–3 и врагов на линии.
- Для матчапа STRATZ оцениваем преимущество по сравнению с общим WR героя в той же паре медалей. OpenDota сравнивается с 50% как отдельная приблизительная схема.
- Не называем эти данные «текущим патчем», пока не подтверждена и не внедрена фильтрация по версии.

## Требуется проверить в пользовательском окружении

1. Получить STRATZ_API_TOKEN лично, не публикуя его в репозитории.
2. Проверить GraphQL на реальном токене (ответы разных рейтингов и новых героев).
3. Проверить отображение портретов из Steam CDN на Windows.
4. Проверить изменение кандидатов при переключении ранга и противников.
5. Сопоставить контрпики STRATZ с результатами матчей; коэффициенты модели пока эвристические.
