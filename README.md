# Dota Helper

Dota 2 Draft Assistant — настольная программа для Windows на C# / .NET 10 / WPF.

## Версия 0.4 — главные контрпики по всей команде + два режима выбора

- Пулы героев: **По ролям** (все подходящие независимо от популярности) и **Эксперимент** (все герои с предупреждением о нестандартной позиции).
- У каждого противника можно вручную указать позицию: 1 керри, 2 мид, 3 оффлейн, 4/5 поддержка, либо «неизвестна». Нельзя угадывать позицию по порядку выбора героев.
- Контрпики вычисляются против ВСЕХ выбранных вражеских героев. Коэффициенты: ядро 1/2/3 — 1.7, поддержка 4/5 — 1.0, неизвестная позиция — 1.2; противник на твоей линии получает ×1.25.
- Недоступные матчапы влияют нейтрально, а не превращаются в автоматическую победу.
- Результат показывает вклад каждого известного противостояния в оценку. Коэффициенты модели предварительные, не проверены исторической выборкой.
- Можно вручную выбрать рейтинг или определить публичную медаль по Steam Account ID / SteamID64 / числовой ссылке профиля. Для Immortal пока используется общая статистическая выборка.
- Режимы статистики: **Мой рейтинг** (срез по рангу) и **Профессиональная мета** (агрегаты pro_pick/pro_win из OpenDota). Если pro-данные отсутствуют, показывается «нет данных», а не статистика другого источника.
- **Важно:** используемые OpenDota matchup-данные относятся к матчам лиг и пока НЕ фильтруются по рейтингу игрока, позиции или актуальному патчу. Переключатель меты меняет базовый WR и популярность, а не источник контрпиков.
- Не требуется различать Ranked All Pick и обычный All Pick: анализ героев одинаков.

### Предыдущая версия 0.3 — подбор по ролям

- Драфт 4 союзников и 5 противников, выбор своей позиции 1–5.
- Отметка противников на линии (повышенный вес в ранжировании).
- Контрпики на основе агрегированных OpenDota matchup-данных с консервативным сглаживанием.
- Общий винрейт и приблизительная частота выбора героев по доступным рейтинговым категориям OpenDota.
- В версии 0.4 устаревшие фильтры заменены двумя режимами пула; избранные остаются бонусом при оценке.
- Избранные герои и настройки сохраняются между версиями.
- Для каждой позиции 1–5 применяется свой **ручной предварительный пул героев**, отдельно от широких тегов OpenDota Carry/Support/Disabler. Это временная проверка допустимости роли, а не статистика по патчу.
- Wraith King и Lifestealer не рекомендуются в стандартных пулах поддержки, а Crystal Maiden — на первую позицию, даже при высоком **общем** винрейте.
- Режим «Эксперимент: все герои» показывает нестандартные пики с предупреждением.
- Общий WR и частота выбора подписаны как статистика **по всем ролям**, а не по выбранной позиции.
- Дисковый кэш (каталог 7 дней; heroStats 3 часа; матчапы 24 часа).

**ВАЖНО:** 0–100 — эвристический рейтинг, НЕ вероятность победы. Общие теги (Carry/Support) **не равны позиции**; матчапы **не являются результатами линии**. OpenDota API не гарантирует фильтр по текущему патчу для используемых агрегатов. Рейтинг /heroStats и контрпики /matchups относятся к разным выборкам. Синергия союзников пока НЕ оценивается. Статистика Immortal может быть недоступна, поэтому в интерфейсе только доступные категории от Рекрута до Божества.

Редкие герои теперь не исключаются в режиме «По ролям». Избранные остаются в отдельном списке настроек и добавляют небольшой бонус к оценке.

**Ограничение:** списки героев всех пяти позиций составлены вручную и не отражают автоматически текущий патч. Подходящий для позиции герой — не обязательно лучший выбор в конкретном матче. Статистика OpenDota не разделена по позициям в этом выпуске. Новые и нестандартные герои могут отсутствовать в обычном пуле; их можно увидеть в «Эксперименте».

## Запуск на Windows

Если используешь числовые папки (1, 2, 3…) в `E:\Work\Dota Helper`, клонируй новую копию:

    $root = "E:\Work\Dota Helper"
    $nums = @(Get-ChildItem $root -Directory | Where-Object { $_.Name -match '^\d+$' } | ForEach-Object { [int]$_.Name })
    $n = if ($nums.Count) { ($nums | Measure-Object -Maximum).Maximum + 1 } else { 1 }
    $folder = Join-Path $root $n
    New-Item -ItemType Directory -Path $folder | Out-Null
    git clone https://github.com/Freep-o-0-rn/Dota-Helper.git "$folder\Dota-Helper"
    cd "$folder\Dota-Helper"
    dotnet run --project .\src\DotaHelper\DotaHelper.csproj

Нужен .NET 10 SDK. Visual Studio 2026 поддерживает .NET 10 WPF.

Есть также автономный EXE: вкладка Actions → успешная Windows build → Artifacts (архив `DotaHelper-0.4-win-x64`). ZIP распаковать перед запуском.

## Проверка

    dotnet build src/DotaHelper/DotaHelper.csproj
    dotnet run --project tests/DotaHelper.SmokeTests/DotaHelper.SmokeTests.csproj

Исходники разрабатываются в ветке main, результаты автоматической сборки доступны в GitHub Actions.
