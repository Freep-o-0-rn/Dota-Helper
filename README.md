# Dota Helper — помощник драфта Dota 2

## Версия 0.10 — крупнее портреты и первая автоматическая синхронизация с Dota 2

- Иконки выбора героев увеличены с **43×29 до 48×32** (без обрезки горизонтальных портретов).
- На левой панели появилась кнопка **«Подключить Dota 2»**. Она находит установленную Dota 2 в библиотеках Steam либо предлагает выбрать папку `dota 2 beta`, затем устанавливает конфигурацию **Game State Integration (GSI)**.
- Конфигурация записывается только в `game/dota/cfg/gamestate_integration/gamestate_integration_dota_helper.cfg`. Другие GSI-конфигурации и файлы игры не изменяются.
- Приложение запускает HTTP-приёмник **только на `127.0.0.1:30127`** с индивидуальным локальным токеном. Токен хранится отдельно в `%LOCALAPPDATA%\\DotaHelper\\gsi-local-token.txt`, не в GitHub и не отправляется в STRATZ.
- После установки GSI **перезапусти Dota 2**, чтобы она загрузила конфигурацию. Когда клиент отправляет пиковые/бановые ID (например, при наблюдении за Captains Mode), программа добавляет эти герои в свободные слоты, не стирая ручной драфт.
- При GSI-пакетах **без пиков или банов** приложение показывает, что клиент не передал эти сведения. Это обычное ограничение GSI в All Pick во время выбора: **полного автоматического распознавания чужих пиков в All Pick пока нет**. Ручной драфт работает всегда.
- Подключение и отключение выполняются кнопкой. Есть сообщения «ожидаю пакеты», «получен драфт», «нет пакетов более 12 секунд».
- Режим Captains Mode использует бановые ID отдельно по Radiant/Dire; в All Pick баны объединяются. Реальная рейтинговая группа, модели контрпиков STRATZ и синергий не менялись.
- Это только **чтение локальных данных**: программа не вводит команды в Dota 2, не читает память процесса и не модифицирует исполняемые файлы.

### Проверка живого драфта

1. Нажми «Подключить Dota 2». Если игра не найдена, укажи корень `dota 2 beta` (не папку `cfg`).
2. Перезапусти Dota 2; в помощнике должна появиться пометка о полученных пакетах.
3. Проверь демо/просмотр матча Captains Mode, в котором GSI сообщает `draft`. Портреты пиков/банов должны заполняться.
4. Затем проверь обычный All Pick. Если GSI присылает только фазу и собственного героя, помощник **не должен выдумывать** остальных героев.
5. Сверь, что после клика «Отключить GSI» ручной выбор продолжает работать. При новом `matchid` автоматически очищаются только ранее автоматически поставленные и не изменённые вручную герои.

Важно: GSI не гарантирует доступности полных пиков/банов в каждой игровой фазе. Следующий этап для All Pick — **экранное распознавание видимых портретов** (с пользовательским разрешением и проверкой против ручного драфта).

## Версия 0.9 — компактный Radiant/Dire драфт

- Настройки слева, портреты пиков/банов Radiant и Dire в центре, широкий список рекомендаций справа.
- По пять слотов пиков на команду. Для своей команды это четыре союзника и один слот ПРЕДПРОСМОТРА выбранной рекомендации — он не влияет на расчёт и не считается выбранным героем.

- Баны All Pick — общие для матча, ёмкость редактора 18 ячеек. Это НЕ гарантия фактического количества банов. В Captains Mode по 7 ячеек банов для каждой команды. Ранг не определяет число банов.
- Забаненные герои исключаются из рекомендаций. Показатели WR/контрпики/синергии и их приоритеты не изменены.

- Подробный анализ выбранного героя скрыт по умолчанию и раскрывается по желанию.
- Сохранены два режима пула: По ролям / Эксперимент. Отдельного режима тестового драфта нет.

### Ограничения 0.9

- Баны вводятся вручную, без захвата из клиента Dota 2.
- All Pick отображает баны матча, а не персональные четыре предпочтения банов, задаваемые в клиенте.
- Captains Mode не отслеживает порядок и таймеры фаз банов. Статистика STRATZ пока не отфильтрована строго по последнему патчу.

## Версия 0.8 — текущий патч Valve и надёжность контрпиков

- В шапке программы показывается **номер последнего патча, опубликованного Valve**, с датой. Используется официальный `https://www.dota2.com/datafeed/patchnoteslist?language=english`; кэш 12 часов и пометка об устаревшем кэше при недоступности сети.
- Важно: текущая дата патча **не фильтрует** автоматически историческую статистику STRATZ. Интерфейс честно показывает «STRATZ: несколько патчей». Мы не называем исторический WR статистикой текущего патча.
- Исправлено байесовское сглаживание контрпиков: маленькие выборки притягиваются к винрейту **своего** источника (ранговая база STRATZ или нейтральная 50% для резерва OpenDota). При 20 играх крайний результат влияет существенно слабее, чем при 2000 играх.
- В подробностях рекомендации показывается **достоверность контрпиков** (низкая/средняя/высокая) и процент покрытия всех выбранных противников с учётом размера выборки. Это показатель полноты данных, **НЕ** вероятность выигрыша и **НЕ** статистическая достоверность в смысле p-value.
- Контрпики против позиций 1–3 и противников на линии по-прежнему имеют повышенный вес, синергии союзников сохраняются.
- Добавлены автоматические тесты официального списка патчей, некорректных дат, небольших и больших выборок, а также оценок качества данных.

## Версия 0.7 — синергии союзников и ссылки Steam /id/

- **Синергии:** данные STRATZ `heroStats.matchUp.with` по совместным матчам выбранных союзников и кандидата, с фильтрацией по той же группе рейтинга, что и контрпики. Показывается размер выборки и вклад каждого союзника.
- **Приоритет контрпиков сохранён:** максимальный вклад противников ±17 баллов, синергий ±7. Если данных по совместным играм нет, вклад 0 — не выдумываем преимущество.
- **Интерфейс:** краткий показатель синергии в каждой компактной карточке и подробный разбор союзников в раскрываемой части.
- **Steam:** принимаются числовой Account ID, SteamID64, `https://steamcommunity.com/profiles/...` и `https://steamcommunity.com/id/_FreeP0rn/`. Для /id/ используется публичная XML-страница Steam Community `?xml=1`, без отдельного ключа API.
- **Ограничение:** Valve считает XML-интерфейс устаревшим, иногда он недоступен. Если Steam не отдаёт XML, приложение покажет понятную ошибку и попросит числовой SteamID64.
- **Источники:** синергии и контрпики берутся из исторических данных выбранной группы рангов; они пока не ограничены последним патчем. В режиме «Профессиональная мета» синергии основаны на высокорейтинговых матчах, не только на профессиональных командах.

## Версия 0.6.1 — диагностика авторизации STRATZ

- Кнопка **«Проверить STRATZ API»** в левой панели выполняет минимальный GraphQL-запрос, не раскрывая токен.
- HTTP 401 = авторизация не принята; HTTP 403 с признаками Cloudflare = возможная блокировка запроса до проверки токена; HTTP 403 без признаков защиты = доступ запрещён по неустановленной причине; HTTP 429 = лимит запросов.
- В ответах нет токена или полного текста ошибки сайта, при наличии добавляется безопасный код Cloudflare CF-RAY.
- Копирование токена как `Bearer ...` или в кавычках автоматически нормализуется.
- Для диагностики больше не требуется перевыпускать токен вслепую.

## Версия 0.6 — портреты, реальные позиции и контрпики по рейтингу

- **Оригинальные портреты Dota 2** (Steam CDN): в списке рекомендаций, обоих раскрывающихся списках драфта и рядом с выбранными союзниками/врагами. Если картинка недоступна, выбор героя продолжает работать.
- Две опции пула: **По ролям** и **Эксперимент**. Ручные списки ролей удалены в 0.5.
- **STRATZ**: группировка реальных матчей по позициям 1–5 и выбранной группе рейтингов из двух соседних медалей. Для обычного режима базовый WR героя берётся на выбранной позиции; профессиональный режим показывает общий WR по pro-матчам OpenDota, а роли по высокорейтинговому STRATZ.
- **Контрпики**: STRATZ `heroStats.matchUp` по соответствующей группе рейтингов (если доступны) вместо общих матчапов OpenDota. Данные о противниках на линии не требуют игнорировать остальных врагов. Важнее враги 1–3 позиции (вес 1.7 против 1.0 саппортов), пометка на своей линии даёт дополнительный множитель ×1.25.
- Каждая рекомендация показывает вклад всех известных матчапов и отдельно сообщает **источник**, число игр и условный вклад в рейтинг. Когда STRATZ недоступен, используется **помеченный как резервный OpenDota**; если матчапов нет, влияние нейтральное, данные не выдумываются.
- Два источника могут использовать различные выборки. STRATZ сравнивает матчап с общей базой винрейта героя в той же рейтинговой группе; OpenDota использует нейтральную базу 50%, что является приблизительным подходом.
- Общий балл 0–100 **НЕ** является вероятностью победы.
- Роли и матчапы пока **НЕ** фильтруются строго по последнему патчу. Обновление кэша не означает, что исходная статистика ограничена актуальным патчем.

### Источники и точность

- Для STRATZ нужен личный API-токен: https://stratz.com/api .
- OpenDota служит дополнительным источником общего WR, каталога героев и резервных матчапов.
- STRATZ в этой версии группирует соседние ранги в пары: Рекрут–Страж, Рыцарь–Герой, Легенда–Властелин, Божество–Титан. Точные данные для одной медали не заявлены.
- В профессиональной мете ранжирование по позициям опирается на высокорейтинговую выборку, **не** исключительно на матчи профи; это ограничение явно обозначено в интерфейсе.
- Не определяем роль врага автоматически по порядку его выбора — указывай её вручную, когда она известна.

### Безопасное подключение токена на Windows

Открой PowerShell **в каталоге проекта**:

```powershell
$secure = Read-Host "Токен STRATZ" -AsSecureString
$env:STRATZ_API_TOKEN = [System.Net.NetworkCredential]::new("", $secure).Password
Remove-Variable secure
dotnet run --project .\src\DotaHelper\DotaHelper.csproj
```

Программа считывает токен только из переменной окружения, не пишет его в файлы и не отображает. **Не публикуй токен в GitHub, скриншотах и чате.**

### Если STRATZ пишет «токен отклонён»

В версии 0.6.1 нажми **«Проверить STRATZ API»** и сообщи только HTTP-код и текст диагностики. Токен, заголовок Authorization, содержимое ответа и cookies не присылай. ### Что проверить вручную

1. Выбери позиции 1–5, в том числе «Титан» и режим «Профессиональная мета»; посмотри статус STRATZ и размер пула.
