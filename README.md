# Dota Helper

Dota 2 Draft Assistant для Windows (.NET 10 / WPF).

## Версия 0.5 — позиции по реальным матчам, без ручных пулов

**Ручные списки героев для позиций 1–5 полностью удалены.**

- Роли определяются по статистике реальных матчей STRATZ GraphQL: `heroStats.stats(groupByPosition: true)`, `matchCount`, `winCount`.
- STRATZ здесь предоставляет **объединённые категории медалей**: Рекрут–Страж, Рыцарь–Герой, Легенда–Властелин, Божество–Титан. Не путать их с данными одной медали.
- Пул **«По ролям»** включает героя, если на выбранной позиции сыграно минимум 30 матчей и это не менее 5% всех известных игр героя. Эти пороги предварительные.
- Пул **«Эксперимент»** показывает весь каталог, но предупреждает о неподтверждённых ролях. Если нет достоверной статистики STRATZ и кэша, стандартный пул пуст вместо выдуманных рекомендаций.
- В режиме своего рейтинга учитываем **винрейт на конкретной позиции** (STRATZ). Профессиональная мета использует общий профессиональный WR OpenDota, а подтверждение роли берёт из высокорейтинговой выборки STRATZ **не только профессиональных** матчей — это указано в интерфейсе.
- Контрпики против всех вражеских героев остаются важным фактором. Враги на позициях 1–3 имеют повышенный вес. Источник контрпиков — общие матчапы лиг OpenDota, **не** отдельный ранг или текущий патч.
- Оригинальные портреты Valve, определение ранга Steam, Титан, новые герои, сохранение избранного и компактные карточки сохранены.

### Подключение STRATZ

Для доступа к реальным позициям понадобится **личный API-токен STRATZ**. Получить: https://stratz.com/api .

В PowerShell, в каталоге новой версии приложения:

```powershell
$env:STRATZ_API_TOKEN = "ВСТАВЬ_СВОЙ_ТОКЕН"
dotnet run --project .\src\DotaHelper\DotaHelper.csproj
```

Не присылай токен в переписку, не коммить в GitHub и не сохраняй в открытом BAT-файле.

Для постоянного хранения можешь настроить переменную окружения `STRATZ_API_TOKEN` в профиле пользователя Windows. Приложение не записывает токен в файлы и не выводит в лог.

Кэш статистики хранится в `%LOCALAPPDATA%\DotaHelper\cache` около 3 часов. При ошибке запроса используется только ранее полученная выборка с пометкой «устаревший кэш».

**Ограничения:** доступность запросов STRATZ для конкретного токена не проверена на пользовательском компьютере. Позиционная статистика пока не фильтруется строго по текущему патчу. Показатель 0–100 — эвристический балл, не вероятность победы.

### Обновление в следующую числовую папку

```powershell
$root = "E:\Work\Dota Helper"
$nums = @(Get-ChildItem $root -Directory | Where-Object Name -Match '^\d+$' | ForEach-Object { [int]$_.Name })
$n = if ($nums.Count) { ($nums | Measure-Object -Maximum).Maximum + 1 } else { 1 }
$folder = Join-Path $root "$n\Dota-Helper"
git clone https://github.com/Freep-o-0-rn/Dota-Helper.git $folder
Set-Location $folder
dotnet run --project .\src\DotaHelper\DotaHelper.csproj
```

Тесты: `dotnet run --project tests/DotaHelper.SmokeTests/DotaHelper.SmokeTests.csproj`.

Автономный EXE: GitHub Actions → успешная сборка → Artifacts → `DotaHelper-0.5-win-x64`.
