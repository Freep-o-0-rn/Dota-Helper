# Dota Helper

Windows-приложение с рекомендациями по драфту Dota 2. Разработка ведётся в репозитории Freep-o-0-rn/Dota-Helper.

## Версия 0.1 — первый прототип

- Каталог героев из публичного OpenDota API.
- Ручной драфт: 4 союзника + 5 противников.
- Выбор своей позиции от 1 до 5.
- Отдельная отметка противников на линии (увеличенный вес в рейтинге).
- Рекомендации по статистике противостояний OpenDota.
- Локальные избранные герои, влияющие на рейтинг.
- Кэш API на диске, повторные запросы ограничены.

**Важно:** рейтинг от 0 до 100 — собственная эвристическая оценка, а не процент побед. OpenDota матчапы могут отражать ограниченную выборку матчей, не совпадающую с твоим рейтингом и патчем. Соответствие позициям пока оценивается по общим тегам героев. Синергия союзников пока НЕ рассчитывается. Программа не читает память игры и не управляет персонажем.

## Как запустить (Windows 10/11)

Установи .NET 10 SDK: https://dotnet.microsoft.com/download/dotnet/10.0

Запусти в PowerShell:

    git clone https://github.com/Freep-o-0-rn/Dota-Helper.git
    cd Dota-Helper
    dotnet run --project src/DotaHelper/DotaHelper.csproj

Либо открой проект src/DotaHelper/DotaHelper.csproj в Visual Studio с поддержкой .NET 10 и WPF.

Первый запуск требует подключения к OpenDota для загрузки списка героев. После успешной загрузки список кэшируется. Кэш матчапов хранится до 24 часов перед попыткой обновления. Если сервис недоступен, программа пробует использовать старые сохранённые ответы.

## Технологии

C# / .NET 10 / WPF. Без сторонних NuGet-пакетов в первой версии.

Локальные файлы:
- %LOCALAPPDATA%/DotaHelper/cache — ответы API;
- %APPDATA%/DotaHelper/preferences.json — выбранная роль и избранное.

## Архитектура

- Models — герои, матчапы и слоты драфта.
- Services/OpenDotaClient — сеть, запросы и кэш.
- Services/RecommendationEngine — формирование рейтинга.
- Services/PreferencesStore — настройки пользователя.
- ViewModels/MainViewModel — состояние экрана.
- MainWindow — WPF-интерфейс.

## Статус проверки

Исходники подготовлены, но Windows/WPF сборка пока не проверена в целевой среде. Проверить через dotnet build на Windows перед использованием.
